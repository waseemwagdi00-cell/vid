1) Make a free GitHub account, create a new repository (any name).
2) Upload ALL files of this folder to it (keep the folders; include the hidden .github folder).
3) Open the Actions tab -> "Build APK" -> wait ~10 minutes until green.
4) Open the finished run, download "VideoGrabber-apk" at the bottom, unzip, install app-debug.apk.
If the run is red, open it, copy the error text and send it to Claude.
